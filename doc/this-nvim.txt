*this.nvim* NeoVim's info extract

AREAS ~

Text ~

  `'wrap'` breaks at any char by default. `'linebreak'` makes it break on
  chars defined by `'brakeat'`. Contains blank chars by default.

Notable options                                          *this-nvim-options* ~

Options doc |options|

 - |conceallevel|: Sets the option for concealed text. Mainly affects help
   files.

 - |textwidth|,|tw|: Limit for auto text breaking; 0 to disable; local.

Search & replace ~

  Find in files

  `':vimgrep' /{pattern}/[g][j][f] {path *}`
    - `g`: same as in `:s`.
    - `j`: do not jump to the first match.
    - `f`: fuzzy search.

  Open quick/location lists: `':cw'`, `':copen'`, `':lw'`, `':lopen'`
